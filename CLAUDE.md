# Правила для Claude в этом проекте

- Проект хакатона «Глава → курс». Как что запускать: `README.md`, порядок на тесте: `PLAYBOOK.md`.
- Отвечай по-русски, простыми словами.
- Книги, сканы, видео, `key.json` в git не добавлять. Ветка работы `part-a/pipeline`, `main` не трогать.
- Коммитить редко, крупными кусками, и не спрашивать об этом. Отправлять только если репозиторий закрыт. Автор коммитов нейтральный, без личной почты.
- После тега заморозки не менять `engine/`, `prompts/`, `schema/`, `domain_pack/`.
- Роль модели в конвейере играешь ты: промпты лежат в `work/<глава>/prompts`, ответы пишешь в `work/<глава>/answers`.
- Ничего не придумывать сверх текста главы. Цитаты подставляет программа.
