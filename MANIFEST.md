# Манифест конвейера

Команда: Aura entertainment
Тег заморозки: freeze-v1

## Как работает конвейер

1. **Учебный слой (часть А).** `python run.py next <глава>` режет главу на порции и пишет промпт `work/<глава>/prompts/NN.md`; модель Claude отвечает в `work/<глава>/answers/NN.json` (сейчас это сессия Claude Code, без ключа API); `python run.py build <глава>` собирает слой и маршрутизацию, проверяет цитаты и покрытие.
2. **Задания и анимации.** `python run.py tasks` и `anims` пишут промпты по слою, модель отвечает JSON, `tasks-build` и `anims-build` проверяют ключи и утверждения. Без ответа модели работает запасной путь кодом (`engine/gen_tasks_offline.py`, текстовые петли).
3. **Курс (часть Б).** `python run.py course <глава>` (внутри `run_b.py`) без модели: практикум на открытых данных (`engine/data_practicum.py`: каротаж Volve, рисунок класса A «реальные данные» и задания с ключом из интерпретации Equinor; срез данных один раз готовит `engine/datasets/volve_extract.py`), перерисованные рисунки книги (`engine/figures`; кривые один раз оцифрованы по скану и лежат в `data/<глава>/figures`), схемы шагов, анимации, отчёт о покрытии шаблонами, курс, строка в `metrics.csv`.
4. **Ролики.** `python run.py video <глава> <узел>` → ответ модели → `video-build`: проверка сценария, озвучка, таймлайн, кадры, звук −16 LUFS, субтитры, распознавание речи, паспорт (`passport.json`, читаемый `passport.md`).
5. **Модуль проверки (часть А).** `python run.py review <пакет>` → промпты → ответы → `python run.py review-build`.

Каждый шаг проверяется по схемам организаторов (`schema/official`) и правилам ТЗ; при нарушении сборка останавливается или пишет ошибку.

## Модели

| Этап | Модель | Версия | Где работает | Что уходит наружу | Как заменить |
| --- | --- | --- | --- | --- | --- |
| Учебный слой | Claude через Claude Code: промпт-файл → ответ-файл | Claude Opus 5.5 (`claude-opus-5-5`) | облако Anthropic | текст порции главы | любая модель отвечает на те же промпты; с ключом — `engine/llm_client.py` (`ANTHROPIC_API_KEY`, `LLM_MODEL`) |
| Задания, доменный пакет, сценарий ролика, описание анимаций | Claude через Claude Code | Claude Opus 5.5 | облако Anthropic | слой главы, текст главы | так же; запасной путь без модели есть |
| Модуль проверки | Claude через Claude Code | Claude Opus 5.5 | облако Anthropic | пакет проверки и текст главы | так же |
| Озвучка (основная) | ElevenLabs, eleven_multilingual_v2 | голос Daniel (onwK4e9ZLuTAKqWW03F9) | облако | только текст сценария | порядок голосов в `domain_pack/voices.json`; организаторы 25.11 подтвердили: голос Microsoft не обязателен |
| Озвучка (запасная) | Microsoft Pavel, Microsoft Irina (Windows OneCore, ru-RU) | системные голоса Windows 11 | локально | ничего | следующий голос в `domain_pack/voices.json`, заменяется вся серия |
| Проверка озвучки | Whisper small (faster-whisper 1.2.1, CPU int8) | веса Systran/faster-whisper-small | локально | ничего | папка `models/whisper-small` |
| Рисунки, схемы, кадры роликов, анимации | без модели: расчёт и графика кодом (`engine/scenes`, `engine/figures`, `engine/video`) | — | локально | ничего | — |

Ключи (`ELEVENLABS_API_KEY`, при наличии `ANTHROPIC_API_KEY`) — только переменные окружения, в репозиторий не кладутся.
Главы, книги и ролики не публикуются и в git не попадают (`.gitignore`).

## Запуск

```
python run.py rebuild <глава>         # слой, задания и курс одной командой
python run.py rebuild <глава> video   # то же и ролики главы после правки факта
python run_b.py all --videos --strict # курсы и ролики всех глав из готового слоя
```
