# Инструкция на тест

Что делать, когда откроют новую главу. Код, `prompts/` и `domain_pack/` после тега **не менять**: меняются только ответы модели и файлы главы.

## До 10:00

1. Проверить, что всё работает: `python -m unittest tests.test_engine` (должно быть OK).
2. Поставить тег заморозки:

```powershell
git tag freeze-v1
```

```powershell
git push origin freeze-v1
```

3. Записать тег в `MANIFEST.md` **до** тега, если ещё не записан.

## Когда выдали главу

Вместо `ГЛАВА` — короткое имя латиницей, например `test1`.

1. **Добавить** (язык `ru` или `en`, домен `geology` или `drilling`):

```powershell
python run.py add ГЛАВА "путь к файлу.md" en geology
```

2. Посмотреть вывод: сколько единиц, нет ли «ВНИМАНИЕ» и «распознано с ошибками».
3. **Слой.** Открыть новую сессию Claude в папке проекта и написать: «Сделай слой главы ГЛАВА по PLAYBOOK.md». Claude повторяет, пока порции не кончатся: `python run.py next ГЛАВА` → прочитать `work/ГЛАВА/prompts/NN.md` → записать `work/ГЛАВА/answers/NN.json` → `python run.py build ГЛАВА` → исправить свои ошибки.
4. **Домен** (только для главы другого домена): `python run.py domain ГЛАВА` → ответ в `work/ГЛАВА/domain_answer.json` → `python run.py domain-build ГЛАВА`. Время пишется само в `domains/time_log.csv`. Делать **до** слоя, чтобы заблуждения домена попали в узлы.
5. **Задания:** `python run.py tasks ГЛАВА` → ответ в `work/ГЛАВА/tasks_answer.json` → `python run.py tasks-build ГЛАВА`.
6. **Курс:** `python run.py rebuild ГЛАВА`: слой попадает в `data/`, картинки и курс собираются сами. Открыть `out/ГЛАВА/index.html`.
7. Просмотреть курс глазами новичка: путь, один шаг, задания.

8. **Ролик на назначенный узел** (организаторы называют узел): `python run.py video ГЛАВА УЗЕЛ short` → прочитать `work/ГЛАВА/video_prompt.md` → ответ в `work/ГЛАВА/video_answer.json` → `python run.py video-build ГЛАВА preview` → посмотреть кадры `out/video/ID/preview_*.jpg` → `python run.py video-build ГЛАВА`. Рендер шортса около 3 минут, разбора около 8. Если нужен голос ElevenLabs, перед запуском в этом же окне задаётся `ELEVENLABS_API_KEY`; без ключа ролик выйдет голосом Windows. Если ни одна сцена не подходит, честный ответ «нужна новая» попадает в отчёт о покрытии.
9. **Анимации остальных видеоузлов:** `python run.py anims ГЛАВА` → ответ в `work/ГЛАВА/anims_answer.json` → `python run.py anims-build ГЛАВА preview` → посмотреть `out/anim/ГЛАВА` → `python run.py anims-build ГЛАВА` (около 40 секунд на петлю, можно оставить считать). Без этого шага узлы получат простые текстовые петли.
10. **Всё вместе и отчёт о покрытии:** `python run.py rebuild ГЛАВА` (нужен `pip install -r requirements.txt`).

Что уже сделано и какой шаг следующий: `python run.py status ГЛАВА`.

## Сколько это занимает

Репетиция 25.11 на Барабошкине (15 страниц, 62 единицы, 22 узла), время Claude и компьютера:

| Шаг | Время |
| --- | --- |
| Нарезка и слой (3 порции, проверка) | 6 мин |
| Задания с проверкой ключей | 1 мин |
| Описание 14 анимаций | 3 мин |
| Сценарий ролика и пробные кадры | 2 мин |
| Рендер 14 петель (в фоне) | 5 мин |
| Рендер шортса | 3 мин |
| Курс и проверки | 1 мин |

Вся глава — около 15–20 минут. Рендер петель и ролика запускать сразу в фоне и переходить к следующей главе. Две главы удобно вести в двух сессиях Claude: файлы у них разные, `python run.py` друг другу не мешает. Рендер двух роликов сразу замедляет оба.

Порядок, если времени мало: слой → задания → курс (это уже сдаваемый результат) → ролик → анимации.

## Английская глава и бурение

Репетиция 25.11 на выдуманном тексте `tests/demo_drilling_en.md` (5 страниц, английский, бурение): от добавления до курса, анимаций и пробных кадров ролика около 10 минут, из них доменный пакет 2 минуты.

- Узлы пишем по-русски, слова для цитат берём из оригинала. Числа и единицы не пересчитываем: ft, psi, ppg остаются.
- `may`, `usually`, `often`, `unless`, `if` обязаны остаться в русском тексте: `может`, `обычно`, `часто`, `если`. Проверка ловит потерю, перевёрнутое направление (`higher` → «ниже») и лишнее «всегда».
- Сцена `wellbore` принимает единицы книги: `grad: 0.052`, `water: 8.33`, окно плотностей — `in_density: true`. Образец: `tests/scene_demos/wellbore_ppg.json`.
- Заданий нужно не меньше 15, иначе `rebuild` остановится на шаге «задания».
- После курса собрать словарь и ИТ-мосты пакета бурения:

```powershell
$env:DOMAIN='drilling'; python engine/domain_build.py --domain drilling --chapters data/ГЛАВА; Remove-Item Env:DOMAIN
```

## Пакет с закладками

1. `python run.py review "путь/package.json"` (для бурения добавить `drilling` в конце).
2. Новая сессия Claude: «Проверь пакет по промптам work/review_ИМЯ/prompts, ответы в answers». Кадры PNG Claude открывает сам.
3. `python run.py review-build "путь/package.json"` → сдать `work/review_ИМЯ/review.json`.

Ложных тревог допустимо две на весь пакет, поэтому замечание пишем, только если есть строка главы, которой элемент противоречит.

## Как Claude работает над порцией

- Прочитать промпт целиком, образец ответа: `data/latyshova/answers/04.json`.
- Исправить все `[error]` в своих ответах, кроме `NOT_COVERED` у ещё не сделанных порций.
- Каждый `[suspect]` перечитать: если потеряно условие, оговорка или перевёрнуто направление — исправить.
- Не трогать `engine/`, `prompts/`, `schema/`, `domain_pack/`, чужие главы.
- Числа только из своей единицы, описания рисунков нейросетью не цитировать, нечитаемое писать в `scan`.

## Что считать ручной правкой

Всё, что изменено **после первого сырого прогона** шага, даже если правил Claude. Исправления по сообщениям `build` внутри прогона порции — часть прогона. Правка руками или по просьбе человека:

```powershell
python run.py log ГЛАВА data/ГЛАВА/layer.json 5 1 1 "что исправлено" "почему"
```

5 — минуты, 1 — сколько человек, 1 — номер прогона. Потом коммит: журнал должен совпадать с историей.

## Отчёт о покрытии шаблонами

`data/ГЛАВА/routing.json`: у каждого видеоёмкого узла поле `template`. Если ни один шаблон не подходит, в отчёте пишем «нужен новый».
