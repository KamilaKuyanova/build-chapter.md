# Глава → курс

Конвейер: глава книги → учебный слой (JSON) → курс. Нужен только Python 3.10+, сторонних библиотек нет.

## Запуск

1. Положите в `input/` папку `books md` с главами и `пакет_вводных` в `input/org/`. Папка `input/` в репозиторий не попадает: главы публиковать нельзя.
2. Нарежьте главы: `python run.py units all`
3. Слой: `python run.py next <глава>` пишет промпт очередной порции в `work/<глава>/prompts/NN.md`. Ответ модели (JSON) сохраните в `work/<глава>/answers/NN.json` и повторяйте, пока порции не кончатся.
4. Сборка и проверка: `python run.py build <глава>` даёт `layer.json`, `routing.json`, `coverage.json`, `check.json`.
5. Проверка чужого пакета: `python run.py review <package.json>`, ответы в `work/review_<пакет>/answers/`, затем `python run.py review-build <package.json>`.

Модель заменяема: движок только пишет промпты и читает JSON. Сейчас отвечает Claude в Claude Code, API-ключ не нужен. Порции одной главы идут по порядку: следующая знает термины предыдущих.

Результат проверки: `work/<глава>/check.json` и `work/<глава>/coverage.json`.

## Что где

| Папка | Что внутри |
| --- | --- |
| `engine/` | Движок, про геологию ничего не знает: нарезка, проверка схемы, проверка слоя |
| `schema/` | Схемы организаторов без изменений |
| `domains/geology/` | Доменный пакет, отдельно от кода |
| `chapters.json` | Главы: файл, страницы PDF, границы. Без `parts` берётся весь файл |
| `tests/` | `python -m unittest discover tests` и `python tests/selfcheck_chapters.py` |
| `work/` | Всё сгенерированное, в репозиторий не попадает |

## Договорённости

- Единица главы: `p095.03`, третья единица на стр. 95.
- Описания рисунков в md написаны нейросетью. Они помечены `figure_ai`, цитировать их как автора нельзя.
- Наши поля сверх схемы: `node.units` (какие единицы пересказаны в узле), `worked_examples[].number`, `layer.uncovered` (`[{unit, reason}]`).
- `error` в проверке — факт, `suspect` — подозрение на искажение смысла, решает смысловая проверка.
- Ручные правки на тесте: `python run.py log <глава> <файл> <минуты> <людей> <прогон> "<что>" "<почему>"`
- `key.json` контрольного пакета до прогона модуля проверки не открываем.
