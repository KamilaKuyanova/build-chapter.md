# Мастер-чек-лист ТЗ «Глава → курс»

Источник: «ТЗ хакатона Глава → курс — для участников» (docx, 21 стр. + html). Отмечайте `[x]` только когда пункт проверен.
(О) = обязательно по ТЗ. Баллы: слой 15, курс 15, видео 10, двойники 30, сдвиг 5, закладки 10, ручной труд 10, запуск 5.

## 0. Организационное
- [ ] Команда 3–5 человек; минимум 3 роли из 4: геология/геофизика; педагогика/журналистика/сценарий; ИТ; дизайн/3D/моушн (**уточнить у организаторов про команду из 2 человек**)
- [ ] Получить на старте пакет вводных: главы (md + изображения страниц), анализы книг, схема и шаблоны (JSON схема учебного слоя, паспорт ролика, таблица покрытия, шаблон доменного пакета, формат внешнего пакета, формат заданий JSON, формат иллюстраций), «Подача доменов геологии», карта доменов, вики, портреты зрителя, открытые данные (Volve, F3), эталонный атом, контрольный пакет закладок с ключом, библиотека референсов, антипримеры, пилотный ролик, список заблуждений, легенда и стайлгайд, словарь ударений
- [ ] Короткое чтение к главам (Латышова: §1–2, §4, §10, §12–16 + таблица обозначений; Басниев: гл. XVIII §4, XIX, XX §2–3 + глоссарий; карточки-предпосылки и лист опечаток для контрольных)
- [ ] Главы и ролики НЕ публиковать: никаких общих ссылок и облачных просмотров с открытым доступом
- [ ] Манифест конвейера: каждый инструмент и модель с версией и пометкой, уходят ли данные во внешний сервис; версии фиксируются в теге заморозки
- [ ] Модель заменяема, конвейер не привязан к поставщику
- [ ] Данные только открытые; корпоративные данные не используются

## 1. Выборки
- [ ] Обучающие: Латышова гл. V §17–20 (стр. 90–108, И/Пр/Н); Басниев гл. XXIII + XXIV §1 (474–500, Ф/М); Кузнецов гл. 10 §10.1–10.4 (200–222, Р/В/П; нужны сканы: карты и разрезы повреждены)
- [ ] Контрольные (самопрогон, не оценивается): Вендельштейн/Резванов гл. I (9–14, 20–30); Баренблатт/Ентов/Рыжик §4 (38–51); Барабошкин §1.2 «Дельты» (30–44)
- [ ] Тест (после заморозки): 3 двойника другой школы и языка (возможно английский) + сдвиг (другой домен нефтегаза, например бурение)
- [ ] Конвейер не подгоняется под конкретные главы

## 2. Конвейер (порядок фиксирован)
- [ ] Глава → учебный слой → маршрутизация → спецификация сцены → курс/ролики
- [ ] Учебный слой — единственный источник правды (курс, ролики, задания не берутся из книги напрямую)
- [ ] Ошибка исправляется в слое и пересобирает зависимое
- [ ] Доменный пакет отдельно от движка: глоссарий RU/EN, заблуждения, чек-лист физики, ИТ-мосты, стайлгайд, словарь ударений и произношений
- [ ] Модуль проверки принимает внешний пакет в схеме организаторов, выдаёт замечания со страницей источника
- [ ] Журнал ручных правок с минутами (совпадает с историей коммитов)
- [ ] Метрики: человеко-минуты и деньги на узел и на минуту видео, доля ручного труда, минуты ментора
- [ ] Репозиторий с тегом заморозки, плейбук, промпты, инструкция запуска, перечень моделей и способ замены

## 3. Часть 1 сдачи: учебный слой (схема организаторов, JSON)
- [ ] Порядок узлов для неспециалиста + обоснование «почему этот узел раньше»
- [ ] Ни один термин не используется раньше узла, где он объяснён
- [ ] Полнота 100% по единицам главы (абзац, рисунок, формула, таблица, пример, задача); таблица покрытия: единица → узел или причина, почему нет; ничего не пропускается как «непоказуемое»
- [ ] Число утверждений в узле не ограничено; узел делится, плотные разделы не сжимаются
- [ ] Разобранные примеры автора (условие, шаги, итог с числами автора) и задачи книги (номер, формулировка, нужный рисунок) — отдельные поля
- [ ] Слои «механизм → практика → нюансы» и ветки «глубже»
- [ ] Поля: тип трудности (основной и второй); утверждения (наблюдение/вывод/допущение) со страницей и дословной цитатой; пометка у каждого поля, написано ли моделью; связи с типом (предпосылка, пример, опровергает заблуждение, переход к данным); заблуждение; «что это значит для данных и что здесь ломается»; ИТ-аналогия и где ломается; «как это делается сейчас»; метка пороговой идеи; линза неэффективности (входные данные, ручные шаги, точки суждения, время, типичные ошибки)
- [ ] «Что это значит для данных» — только выводы, прямо следующие из главы; остальное гипотеза
- [ ] Машинная проверка: цитата находится на указанной странице; каждое число в тексте узла и курса есть в исходной единице главы
- [ ] Устойчивые идентификаторы узлов (ролик, текст, исправление ссылаются на одно место)

## 4. Часть 2: маршрутизация форматов
- [ ] Для каждого узла: формат (шортс, длинное видео, интерактив, практикум на данных, карточки, текст) с обоснованием по типу трудности (М, В, И, Ф, П, Пр, Н, Р)
- [ ] Критерии видеоёмкости: изменение во времени, невидимое становится видимым, скачок масштаба, контринтуитивность, причина→следствие
- [ ] Шортсы-крючки без своего узла ≤ 10–20% роликов

## 5. Часть 3: демо-курс на каждую главу (собирается конвейером, не вручную)
- [ ] Открывается локально в браузере, без сервера и логина
- [ ] Путь: части и шаги в порядке графа, время на шаг, прогресс, возврат к месту остановки
- [ ] Задания: ≥15 на главу, ≥4 типов из 5 (один ответ, несколько, порядок с перетаскиванием пальцем, пропуск в тексте, расчёт); проверка сразу; верный ответ и пояснение в одну фразу; ответ есть в тексте шага; у задания ссылка на утверждение узла; формат заданий JSON организаторов
- [ ] Карточки повторения на ВСЕ узлы с отметкой «знаю / повторить»
- [ ] Конспект (суть шага и выводы для данных), печать в PDF
- [ ] Карта связей шагов
- [ ] Медиа по маршрутизации; иллюстрации по правилам
- [ ] Хотя бы один шаг на главу «решение на данных» (признаки → правило → вывод): ролик, интерактив или задание на открытых данных
- [ ] Страница шага — блоки (пустые не показываются): заголовок 3–7 слов + название книги; суть 2–3 фразы; как это работает (фразы ≤20 слов, термин выделен и объяснён); по шагам; разбор примеров; цифры и условия; новые понятия; формулы (только из главы, с расшифровкой и единицами); таблицы книги целиком (исправления OCR помечены и в листе опечаток); частая ошибка; что это значит для данных; аналогия с границей; источник «стр. N» у КАЖДОГО абзаца, цитаты, видно автор/модель; задачи из книги; иллюстрации ≥1 на шаг

## 6. Визуальная часть и интерфейс курса
- [ ] ≥1 иллюстрация на шаг; ≥1 рисунок/анимация класса A или B на часть главы
- [ ] Классы: A данные (код из данных, генерация нет), B механизмы (детерминированная графика, генерация нет), C внешний вид (фото с источником или «иллюстрация ИИ»), D атмосфера
- [ ] (О) На сгенерированных иллюстрациях запрещены: керн, шлифы/микроскопия, разрезы и схемы недр, графики и кривые, надписи, цифры, логотипы, читаемые экраны
- [ ] (О) Метка «иллюстрация ИИ» на самой картинке; подпись описывает изображённое
- [ ] Рисунок книги, на котором держится пример/задача, перерисован кодом по скану с подписью «перерисовано по рис. N, стр. M»; вставлять рисунки книги в курс нельзя
- [ ] (О) Телефон 390 px и десктоп 1280 px без горизонтальной прокрутки (широкие таблицы прокручиваются внутри)
- [ ] Текст ≥16 px, строка ≈≤70 знаков; светлая и тёмная тема
- [ ] Навигация: путь, оглавление страницы шага, назад/дальше, прогресс
- [ ] Доступность: alt-тексты, видимый фокус, переход к содержанию с клавиатуры, отключение анимаций по системной настройке
- [ ] Цвета пород, флюидов и кривых по легенде/стайлгайду организаторов
- [ ] Курс без видео ≤30 МБ на главу

## 7. Часть 4: ролики и паспорт ролика
- [ ] Два ролика по обучающим главам на разных главах: шортс 9:16 и разбор 16:9; в главе без ролика видеоузлы закрыты интерактивом/анимацией, спецификация сцены в паспорте
- [ ] Паспорт: карточка узла; сценарий с таймкодами; таблица источников «утверждение → страница/датасет»; спецификация сцены (объекты, параметры, инварианты, допущения); класс каждого кадра (A–D) и метка происхождения; список преувеличений; вопрос-предсказание и вопрос на перенос; мост «где здесь данные и ИТ»
- [ ] Ролик пересобирается из спецификации, а не только из файла монтажа
- [ ] Спецификации проходят проверку менторов ДО рендера (слот, таблица источников)
- [ ] Шаги кадров A/B: разбор референса → спецификация сцены как данные → сцена в управляемом инструменте, данные из той же модели → сборка (тайминг, субтитры, озвучка, формат) → проверка по чек-листу до рендера
- [ ] Кадры A и B вычисляются из данных/расчёта; генерация видео или интерполяция в них — нарушение
- [ ] Правила генерации: первый и последний кадр из проверенного рендера/фото; клипы 3–6 с; геометрия задаётся 3D-болванкой, модель только фактура и свет; текст, цифры, оси, стрелки только на монтаже
- [ ] Метка происхождения на каждом кадре: «реальные данные», «симуляция», «схема»
- [ ] (О) Ровно два формата: шортс 9:16 один механизм 40–75 с (≤90); разбор 16:9 1,5–3 мин, синхронные виды рядом
- [ ] (О) Крючок в первые 3 с (вопрос, парадокс, нарушенное ожидание, не определение)
- [ ] (О) Смысл каждого шага через «зачем/иначе»; термин объяснён при первом упоминании за 2–3 с
- [ ] (О) Пауза на предсказание, финальное состояние держится на экране, в конце вопрос на перенос
- [ ] (О) Единая легенда организаторов
- [ ] (О) Читаемость: подписи в безопасной зоне, ≤7–8 слов, ≥1,5 с на подпись, без формул и греческих букв; понятны без звука; субтитры (отключаемые)
- [ ] Узнаваемый мир по фото-референсам (список в паспорте); непрерывный мир; мини-карта при смене масштаба; синхронные виды; кривая синхронна с прибором
- [ ] Ритм: шаг каждые 3–5 с, затемнения ≤0,5 с; таблицы и формулы не в шортс
- [ ] Финал: карта шагов, петля или анонс
- [ ] Хотя бы один кадр серии в истинном масштабе, без вертикального преувеличения; в остальных преувеличение подписано числом
- [ ] Стайлгайд: цвета литологии/кривых, полярность сейсмики, оси; названа выбранная конвенция (русская/международная)
- [ ] Компоновка 9:16: планшет ГИС вертикален; разрезы/карты перекомпонуются или ведутся камерой
- [ ] Устаревшая техника с пометкой «исторический прибор» + «как это делается сейчас»

## 8. Честность в роликах
- [ ] (О) Плашка «не в масштабе» + названо, что именно преувеличено
- [ ] (О) Наблюдение отделено от интерпретации (стрелка «сигнал → вывод» видна)
- [ ] Правило вместе с контрпримером
- [ ] Показано, откуда доверие к числу (калибровка, керн, соседняя скважина)
- [ ] Если два случая дают похожие данные, это сказано

## 9. Озвучка
- [ ] (О) Фраза ≤15–18 слов, одна мысль; формулы и числа словами с единицами в нужном падеже; аббревиатуры раскрыты; словарь произношений (ПС, ГК, Rw, Sw, ВНК)
- [ ] (О) Голос не говорит больше источника: у каждой фразы id утверждения узла; аналогия названа аналогией
- [ ] (О) Синхрон голос/кадр ≤0,5 с по меткам слов
- [ ] Голос не дублирует экран дословно
- [ ] 110–150 слов/мин; пауза 1–1,5 с перед ответом; один голос и темп на серию
- [ ] −16 LUFS, без клиппинга, фраза не обрезается; музыка −20 дБ
- [ ] Голоса Microsoft (ru, kk), наружу только текст сценария; запасной путь (другой синтез или локальный голос)
- [ ] Проверка: ASR локальной моделью, ошибок ≤10%, темп/громкость/синхрон в паспорте; спорные ударения в список «проверить на слух»

## 10. Чек-лист физики (ошибка «нет» без оговорки = ошибка)
- [ ] Слои: порядок сохраняется; разлом смещает согласованно; несогласие как событие
- [ ] Флюиды: нефть/газ в порах; газ над нефтью над водой, контакт горизонтален (иное — с оговоркой); от высокого давления к низкому; покрышка
- [ ] Причина раньше следствия; баланс; согласованные виды (разрез/план/поверхность)
- [ ] Механизм прибора верный (ГК — собственное излучение, не «отражение»; плотностной метод); сигнал отделён от свойства; условия применимости (знак ПС); кривая из той же модели
- [ ] Правдоподобные числа (не «300° у долота»); преувеличения названы
- [ ] Объекты не меняют конструкцию между кадрами; нет неправдоподобных совмещений
- [ ] Глубина растёт вниз; шкалы/единицы/полярность подписаны; метка соответствует способу создания; техника современная или помечена исторической
- [ ] Бурение (для сдвига): гидростатика, газ в закрытой/открытой скважине, объём в ёмкости, конструкция скважины неизменна
- [ ] Ролик не закрепляет заблуждения (список 14 + 6 добавленных): озеро нефти, динозавры, пласт=пустота, пористость=проницаемость, сейсмика видит нефть, высокое сопротивление=нефть, ГК «отражается», ВНК всегда резкий, запасы=одно число, керн=шлам, обсаженная скважина пропускает без перфорации, вышка над скважиной, кривая=порода, модель знает точно; тонкий пласт «не существует», давление как звук, высокая амплитуда=УВ, ГК=глинистость напрямую, газовая пачка не меняет давление, пористость рифов не меняется
- [ ] Уровни: критическая (заблуждение, неверный механизм, нарушена причинность) = ролик 0 и исключён; существенная = снижает балл; допустимое упрощение с оговоркой = плюс

## 11. Часть 5: прогоны на тесте
- [ ] Слой, маршрутизация и демо-курс по каждой главе собирает замороженный конвейер целиком (путь, страницы шагов, задания, карточки, иллюстрации)
- [ ] Один ролик на всю тестовую выборку на узел, назначенный организаторами + отчёт о покрытии шаблонами по каждому видеоёмкому узлу двойников (какой шаблон с какой моделью состояния или «нужен новый»)
- [ ] Сдвиг (сокращённо): слой и маршрутизация, доменный пакет и время сборки, отчёт о покрытии шаблонами, один ролик (на узел, назначенный организаторами)
- [ ] Ручные правки записаны в журнал с минутами
- [ ] Модуль проверки работает на пакете с закладками (чужой черновик: утверждения, сценарии, спецификации сцен, кадры)
- [ ] Контрольный прогон — сами, не сдаётся

## 12. Закладки (10 баллов)
- [ ] ≥70% найденных ошибок с исправлением и страницей, ложных тревог ≤2 (находка полностью — с исправлением и страницей, наполовину — без; пометка верного = ложная тревога)
- [ ] Типы закладок: сверхобобщение, переворот знака, измеренное вместо выведенного, потеря условия, пропуск оговорки, неверный закон масштаба, неверный механизм, устаревшее как текущее, ИТ-аналогия без границы, ошибки кадров
- [ ] Лучше «обычной LLM с запросом найди ошибки»; тяжесть: критическая 3, значимая 2, незначительная 1
- [ ] Откалибровать на контрольном пакете с ключом

## 13. Допуск, заморозка, сдача
- [ ] Допуск: пакет полный (части 1–6), демо-курс открывается локально по инструкции
- [ ] Заморозка до выдачи тестовых глав: код, промпты, доменный пакет не меняются; тег версии
- [ ] У каждого утверждения ссылка на страницу
- [ ] 0 критических ошибок (2 и больше = без призового места)
- [ ] Запуск: жюри запускает по инструкции без помощи; после правки факта в слое страница шага и ролик пересобираются ОДНОЙ командой
- [ ] Ручной труд: ≤30 чел-мин на тестовую главу идеал (≤90 средне, >180 плохо)
- [ ] Панель новичков проходит курсы: цель ≥80% решённых задач
- [ ] Желательно: интерактив на открытом датасете (кривая/разрез из той же модели, что в кадре)
