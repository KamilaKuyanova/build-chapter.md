# Доменный пакет: геология (по шаблону организаторов `domain_pack_template.md`)

Движок не знает геологии: всё предметное лежит здесь. Пакет выбирается переменной окружения `DOMAIN`
(`geology` → эта папка, иначе `domains/<домен>/`); код подключает его только через `engine/domain.py`.

| Файл | Что внутри | Откуда |
| --- | --- | --- |
| `glossary.md` | термины RU/EN: термин, определение, западный аналог, где введён, страница | собран из слоёв глав (`engine/domain_build.py`) + `glossary_en.json` |
| `glossary.json`, `glossary_en.json` | термины из анализов книг; западные аналоги (перевод модели, помечен «сверить») | импорт анализов, модель |
| `misconceptions.json` | заблуждения `misc.*` | заготовка организаторов |
| `physics_checklist.json` | чек-лист корректности `pc.*` | заготовка организаторов |
| `it_bridges.md` | ИТ-аналогии узлов и где они ломаются | собран из слоёв |
| `styleguide.json` | цвета пород, флюидов, кривых, метки происхождения | заготовка организаторов |
| `pronunciation.md` | как читать аббревиатуры и обозначения | заготовка организаторов |
| `stress_dictionary.md` | ударения в терминах (U+0301) | заготовка организаторов |
| `errata/<глава>.md` | листы опечаток распознавания: места `needs_scan` со страницами | собран из слоёв |
| `templates/registry.json` | 8 шаблонов сцен по типам трудности и их модели состояния | движок `engine/video/templates` |
| `templates/<шаблон>.json` | параметры-образцы шаблонов для геологии | этот пакет |
| `legacy_notes.json` | устаревшие разделы книг → «как это делается сейчас» | анализы книг |
| `viewer_portraits.md` | портреты зрителя | заготовка организаторов |
| `pack_build_log.csv` | время сборки пакета (машинное и человеко-минуты) | `engine/domain_build.py` |

## Команды

```
python engine/domain_build.py --domain geology --chapters data/latyshova data/basniev data/kuznetsov
python engine/domain_build.py --new drilling                  # заготовка пакета нового домена (сдвиг)
DOMAIN=drilling python engine/domain_build.py --domain drilling --chapters data/<глава_сдвига>
```

Для нового домена: заготовка копирует общие файлы (заблуждения, чек-лист, стайлгайд, произношение), а глоссарий,
ИТ-мосты и листы опечаток собираются из слоя главы сдвига. Чего нет в пакете домена (например, образцов шаблонов),
берётся из пакета геологии — это видно, и время доводки пакета записывается в `pack_build_log.csv`.
