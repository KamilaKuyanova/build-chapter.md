# Проверка курса и роликов на новичках (бланк)

ТЗ: «новички решают не меньше 80 % задач по курсу» (оценка демо-курса) и «новичок отвечает на вопрос-предсказание и вопрос
на перенос» (оценка видео); «собственная проверка роликов на новичках до финала» поднимает в рейтинг.

## Кого звать
2–3 человека **без геологического образования** (лучше всего — ИТ-специалисты, как зрители курса из `domain_pack/viewer_portraits.md`).

## Курс (15–25 минут на главу)
1. Откройте `out/<глава>/index.html` на компьютере тестирующего (или в окне шириной с телефон).
2. Попросите пройти 5–8 шагов подряд и решить задания «Проверь себя» **сами, без подсказок**. Время засекать не нужно.
3. В конце — на странице «Путь» кнопка **«Скачать мои результаты»**: файл `результаты_….json` сохранится на компьютер.
   Курс ничего не отправляет в интернет.
4. Положите файлы в `novice_test/results/` (папка в git не попадает) и выполните:

```
python novice_test/report.py
```

Отчёт `novice_test/report.md`: доля заданий, решённых с первой попытки (цель ≥ 80 %), по главам и типам; задания, на которых
ошибалось больше половины тестирующих, — кандидаты на неверный ключ или неясную формулировку.

## Ролики (по 3 минуты на ролик)
Заполните строку в `novice_test/videos.csv` на каждого зрителя и ролик:

| Поле | Что записать |
| --- | --- |
| `tester` | имя или номер (без фамилий) |
| `video` | `latyshova_signs` или `basniev_response` |
| `prediction_correct` | 1 — на паузе с вопросом-предсказанием ответил верно, 0 — нет |
| `transfer_correct` | 1 — на вопрос в конце (перенос) ответил верно, 0 — нет |
| `understood_1to5` | «Понял, почему так происходит?» от 1 до 5 |
| `confusing` | что было непонятно (термин, кадр, слишком быстро) |

Правило: на паузе ролика остановите воспроизведение и спросите ответ **до** того, как его покажут.

## Что делать с результатами
- Задания с низкой решаемостью — сверить ключ и текст шага, при необходимости поправить слой (часть А) и пересобрать курс.
- Непонятные места роликов — в сценарий (`videos/<ролик>/video.json`), затем `python engine/video/make_video.py videos/<ролик>`.
- Итог (доли и выводы) — в защиту: «проверили на N новичках, решаемость X %».
