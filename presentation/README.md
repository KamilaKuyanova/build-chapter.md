# Презентация защиты

Открыть `presentation/index.html` в Edge или Chrome, нажать **F** (полный экран). Интернет не нужен.

| Клавиша | Что делает |
| --- | --- |
| → пробел, клик, колесо | дальше |
| ← или клик в левой четверти | назад |
| F | полный экран |
| N | подсказка с текстом речи |
| M | звук ролика на слайде «Ролик» |

Перед показом и после теста:

```powershell
python presentation/build.py
```

Команда берёт цифры из `data/`, название команды из `MANIFEST.md`, паспорта из `videos/` и готовит ролики в `presentation/media` (в git они не попадают, поэтому на другом компьютере команду надо запустить там, где есть mp4). Когда в `chapters.json` появятся главы `set: test`, слайд «Тест» добавится сам. Снимки курса: `python presentation/build.py shots`.

Если компьютер без видеокарты, чёткость 3D снижается сама. Если WebGL нет, слайды работают без 3D.

Та же команда собирает `out/Защита.html`: всё в одном файле, его можно унести на флешке.

## Речь, около 7 минут

**Старт** (25 с). Мы строили конвейер, который превращает главу книги в курс для новичка. На экране стопка страниц: сейчас она станет слоями породы. Так и работает конвейер: из текста получается структура, в которой видно, что на чём лежит.

**Проблема** (30 с). Пересказать главу сегодня легко. Трудно не соврать. Вот три примера. В книге «порода может разорваться», в пересказе «разорвётся»: пропала оговорка. В книге «если скважина закрыта», в пересказе давление растёт всегда: пропало условие. В книге давление выше, в пересказе ниже. Текст гладкий, новичок ошибку не заметит. Поэтому точность в задании — порог, а не баллы.

**Конвейер** (45 с). Снизу глава, нарезанная на единицы. Над ней учебный слой. Из него задания, анимации, ролики, и сверху проверка. Курс никогда не собирается из книги напрямую, только из слоя.

**Проверка** (45 с). Пример. Автор пишет «may eventually». Нажимаю: модель написала «всегда», проверка сразу поймала потерянную оговорку и лишнее обобщение. Ещё раз: в курс попадает фраза с «может». Текст русский, цитата английская.

**Итог** (30 с). Все единицы трёх глав либо в узлах, либо в списке с причиной. Цитаты ставит программа, а не модель.

**Курс** (35 с). Курс открывается локально, без сервера и входа. На телефоне ничего не вылезает за край. У каждого абзаца страница.

**Анимации** (25 с). Движение нужно там, где без него не понять. Кадры рисует код по параметрам сцены, генеративного видео нет.

**Ролик** (60 с). Клавиша M включает звук. У ролика паспорт: каждая фраза ссылается на утверждение, каждый кадр имеет класс, есть чек-лист физики и проверка озвучки распознаванием.

**Закладки** (40 с). Модуль проверки на контрольном пакете нашёл 19 ошибок из 21 и не тронул верное. Это набор с открытым ключом, на тесте пакет другой.

**Перенос** (40 с). Репетиция на контрольной главе заняла 15–20 минут. Отдельно прогнали английский текст о бурении: пакет домена собран за 2 минуты.

**Тест** (40 с, если есть результаты). Результаты сегодняшнего теста: главы открыли после заморозки.

**Честно** (25 с). Что не идеально: места для сверки со сканами отмечены, шесть рисунков неточные, модель работает через Claude Code.

**Финал** (20 с). Факт исправляется в одном месте, курс и ролик пересобираются одной командой. Готовы показать вживую.
